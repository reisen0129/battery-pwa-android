备份与同步

所有数据仅保存在本机 IndexedDB，不会上传任何服务器。

完整备份（含车辆与全部记录），可拷贝到电脑或云盘自行保存。

标准表格，方便在 Excel / 表格软件中做深度分析或报销。

支持导入 Excel / CSV 数据（合并模式：追加，不删已有）。

生成本期用车报告长图（PNG），便于分享到社交媒体。

危险操作，会删除本机全部车辆与记录，不可恢复。

多设备同步 / 网盘方案（WebDAV 等）

本应用默认纯本地存储（IndexedDB），不联网。如需在多设备间同步，可用以下自托管思路：

  1. 手动导出 / 导入：在每台设备用「导出 CSV / JSON」备份，再在另一台「导入」合并。简单可靠，适合偶尔同步。
  2. WebDAV 网盘：将导出的 JSON/CSV 文件存入支持 WebDAV 的网盘（如 Nextcloud、群晖 NAS、InfiniCLOUD 等）。进阶用户可在此基础上自行编写同步脚本（定时导出 → 上传 WebDAV → 其他设备拉取导入）。
  3. 进阶自托管：把项目部署到自己的静态服务器，配合定时任务做备份归档。本仓库为纯前端，无后端，数据主权始终在你手中。

提示：导入均为「合并」模式，重复数据按 ID 去重，可安全多次同步。

可将本应用「添加到主屏幕」，像 App 一样离线使用。
