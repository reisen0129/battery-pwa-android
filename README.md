# 电车电耗记录 PWA（battery-pwa-android）

一款面向电动车主的**本地电耗记录**工具，纯前端 PWA，数据完全保存在本机，**不上传任何服务器**。可「添加到主屏幕」像 App 一样离线使用。

## ✨ 功能特性

- **记录行驶电耗**：输入初始/剩余电量(%)、满电电量(kWh)、里程(km)，自动计算消耗电量与电耗（kWh/100km）。
- **公式校验**：初始电量低于剩余电量（电量"越跑越多"）时阻止提交，杜绝负电耗异常数据。
- **单次 vs 平均对比**：每条记录显示本次电耗，并与该车辆历史平均对比（低于/高于/接近平均）。
- **语义化配色**：电耗低于平均显示绿色、高于平均显示红色、接近平均显示黄色。
- **列表分页与刷新**：每页 5 条，支持上拉加载更多 + 下拉刷新手势（移动端），附刷新按钮（桌面端）。
- **删除二次确认**：单条记录、清空全部、删除车辆均弹自定义确认框，避免误触。
- **趋势图**：统计页纯 SVG 折线图，支持按月/按周切换（无外部依赖，离线可用）。
- **深色模式**：右上角一键切换，偏好本地保存。
- **导入导出**：导出/导入 JSON 与 CSV（CSV 带 BOM，Excel 可直接打开）；支持 Excel/CSV 数据导入合并。
- **报告长图**：一键生成月度/年度用车报告长图（PNG），便于分享。
- **多设备同步引导**：内置 WebDAV / 网盘自托管同步方案说明。

## 🧱 技术栈

- 纯静态前端：HTML + CSS + 原生 JavaScript（无框架、无构建步骤）
- 数据存储：浏览器 **IndexedDB**（数据主权始终在用户本机）
- PWA：manifest + Service Worker（可安装、可离线）
- 图表：原生 SVG；报告长图：Canvas
- 部署：任意静态托管（GitHub Pages / CloudStudio / 自有服务器）

```

│   └── styles.css        # 全局样式（emerald 主题 + 深浅色支持）
├── js/

├── icons/                # 应用图标（192 / 512）
└── scripts/              # 辅助脚本（如有）
```

## 🚀 本地运行

需通过 http 环境（Service Worker 与 PWA 能力依赖），桌面直接双击 `index.html` 可录数据但安装/离线能力不可用：

```bash
cd battery-pwa-android
python -m http.server 8080
# 浏览器打开 http://localhost:8080
```

手机访问：将项目部署到任意 https 静态托管，再用手机浏览器打开即可「添加到主屏幕」。

## 🔒 数据存储与隐私

- 所有车辆与记录仅存于本机 IndexedDB（`battery-logger-db`），**不联网、不上传**。
- 推荐用「备份与同步」页导出 JSON/CSV 自行保管；多设备可用 WebDAV 等方案手动同步。

## 📦 导入导出字段

CSV 表头：`日期, 车辆, 满电电量(kWh), 初始电量(%), 剩余电量(%), 里程(km), 消耗(kWh), 电耗(kWh/100km), 备注`
导入为「合并」模式，按 ID 去重，可安全多次同步。
